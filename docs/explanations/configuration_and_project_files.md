# Configuration and non-Python project files

This document covers the non-Python files that configure or run the project.

## `.env.example`

Template for environment configuration. Copy to `.env` (gitignored) and fill in
the Mem0 key.

| Variable | Default | Purpose |
|---|---|---|
| `PRODUCT_API_URL` | `http://localhost:8000` | Base URL of the FastAPI catalogue |
| `OLLAMA_BASE_URL` | `http://localhost:11434` | Local Ollama server |
| `OLLAMA_MODEL` | `llama3.1` | Chat model used for extraction and replies |
| `OLLAMA_TIMEOUT_SECONDS` | `120` | Per-request LLM timeout |
| `MEM0_MCP_URL` | `https://mcp.mem0.ai/mcp` | Official hosted MCP endpoint |
| `MEM0_API_KEY` | empty | Mem0 API key, sent as `Authorization: Token …`; never logged |
| `MEM0_TIMEOUT_SECONDS` | `30` | MCP connect/call timeout |
| `MEMORY_EVENT_TIMEOUT_SECONDS` | `15` | Max wait for an async Mem0 write event |
| `MEMORY_EVENT_POLL_INTERVAL_SECONDS` | `1` | Event polling interval |
| `TYPESAFE_API_KEY` | empty | Jev API key, sent as `Authorization: Bearer …`; never logged |
| `JEV_MODEL` | `jev-latest` | Jev model alias |
| `JEV_BASE_URL` | `https://api.typesafe.ai/v1/systemone` | System One endpoint |
| `JEV_TIMEOUT_SECONDS` | `2` | Router timeout before the rules fallback |
| `ROUTER_USE_JEV` | `true` | Force deterministic rules mode when false |
| `ROUTER_CONFIDENCE_THRESHOLD` | `0.5` | Noul/Choice decision threshold |
| `ROUTER_SEND_HISTORY_TURNS` | `2` | Prior turns sent to Jev |
| `APP_ENV` | `development` | Environment label |
| `MAX_RECOMMENDATIONS` | `5` | Number of ranked products returned |
| `MEMORY_TOP_K` | `20` | Memory search/listing limit |

`app/config/settings.py` reads these with `pydantic-settings`. Missing
`MEM0_API_KEY` is not fatal: memory is reported as unavailable and the rest of the
workflow still runs. Missing `TYPESAFE_API_KEY` is also not fatal: the router runs
in deterministic rules mode and the UI says so.

## `.gitignore`

Excludes `.env`, virtual environments, Python caches, pytest caches, Streamlit
secrets and editor/OS files. `.env.example` is explicitly kept.

## `pyproject.toml`

Defines the uv project and is the authoritative dependency source:

- `[project]` — name, version, description, README, `requires-python = ">=3.11"`.
- Runtime dependencies with direct pins (same versions as `requirements.txt`).
- `[dependency-groups].dev` — `pytest` and `pytest-asyncio`; installed by default
  with `uv sync`, excluded with `uv sync --no-dev`.
- `[tool.uv].package = false` — the repository is an application, not a
  distributable package, so uv does not build/install the project itself.

| Package | Version | Why |
|---|---|---|
| `fastapi` | 0.165.0 | Product catalogue API |
| `uvicorn[standard]` | 0.54.0 | ASGI server |
| `streamlit` | 1.67.0 | Chat UI |
| `langgraph` | 1.2.23 | Workflow + checkpointing |
| `mcp` | 2.3.0 | Official MCP client / Streamable HTTP |
| `pydantic` | 2.14.3 | Validation |
| `pydantic-settings` | 2.16.3 | Environment settings |
| `python-dotenv` | 1.2.4 | `.env` loading |
| `httpx` | 0.28.1 | Ollama and product API HTTP |
| `pytest` (dev) | 9.2.0 | Tests |
| `pytest-asyncio` (dev) | 1.5.0 | Async test support available |

No database, vector store, Mem0 SDK or alternative memory library is included.

## `uv.lock` and `.python-version`

`uv.lock` is the fully resolved dependency graph (87 packages including
transitives) generated by `uv lock`. It makes installs reproducible and should be
committed. `.python-version` contains `3.13`, so uv uses/installs Python 3.13 for
this project.

Common commands:

```bash
uv sync                 # create/update .venv from uv.lock (includes dev)
uv sync --no-dev        # runtime only
uv lock                 # re-resolve after changing pyproject.toml
uv lock --upgrade       # upgrade locked versions
uv add <package>        # add a dependency and refresh the lock
uv run pytest           # run inside the project environment
uv tree                 # inspect the dependency graph
```

If dependencies change, update `requirements.txt` as the pip mirror as well.

## `requirements.txt`

A pip-compatible mirror of the direct dependencies (including test dependencies)
for environments without uv:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

The file header says that `pyproject.toml` + `uv.lock` are authoritative. Its
pins match those files, including `python-dotenv==1.2.4`.

## `run.sh`

1. Moves to the repository root.
2. Requires `.venv`; activates it.
3. Warns if `.env` is missing.
4. Starts `uvicorn backend.api:app --port 8000` (from the activated `.venv`) if
   `/health` is not already answering.
5. Traps exit/interrupt to stop the API process it started (not one it reused).
6. Runs `streamlit run app/ui/streamlit_app.py`.

For an explicit uv workflow without the script, use
`uv run uvicorn backend.api:app --port 8000` and
`uv run streamlit run app/ui/streamlit_app.py`.

Ollama is not started by the script because it is an external local service.
Mem0 Cloud is remote and needs no local process. It expects the environment to
be prepared with `uv sync` (or pip) and does not run `uv sync` itself.

Run with `./run.sh` after `chmod +x run.sh` (already executable in the repo).

## `pytest.ini`

- `testpaths = tests`
- `addopts = -q`
- `asyncio_default_fixture_loop_scope = function` (removes a pytest-asyncio
  deprecation warning)
- Registers the `live` marker used for tests that contact Mem0 Cloud.

## `backend/data/products.json`

Synthetic catalogue with 28 products:

- 23 over-ear/on-ear headphones and 5 earbuds.
- Brands: Sony, JBL, boAt, Sennheiser, Anker, Realme.
- Prices ₹1,299–₹29,990, ratings 4.0–4.7.
- Fields: `product_id`, `name`, `brand`, `category`, `price`, `rating`,
  `wireless`, `noise_cancellation`, `features`.
- Top-level metadata: `catalogue_version`, `currency` (`INR`), and a note that
  data is illustrative.

Only `backend/routes/products.py` reads this file. Tests load it read-only to
assert catalogue expectations.
